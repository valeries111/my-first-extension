# Count Latin Characters

## Описание

**Count Latin Characters** — расширение для Visual Studio Code, которое подсчитывает количество латинских букв в выделенном фрагменте текста.

Расширение учитывает только латинские буквы:
- Заглавные: `A-Z`
- Строчные: `a-z`


## Возможности

- Подсчёт заглавных и строчных латинских букв в выделенном тексте.
- Вывод результата в информационном сообщении VS Code.

## Как использовать

1. Откройте файл в Visual Studio Code.
2. Выделите фрагмент текста.
3. Запустите команду `Count Characters`.
4. В правом нижнем углу появится сообщение с количеством латинских букв.

## Пример работы

Выделенный текст:

```text
Hello Привет 123! ABC
```

Результат:

```text
Количество латинских букв: 8
```

## Установка

1. Откройте проект расширения в Visual Studio Code.
2. Выполните команды:

```bash
npm install
```

```bash
npm run compile
```

3. Нажмите `F5`, чтобы запустить Extension Development Host.
