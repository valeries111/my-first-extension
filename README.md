# Count Latin Characters

## Описание

**Count Latin Characters** — расширение для Visual Studio Code, которое подсчитывает количество латинских букв в выделенном фрагменте текста.

Расширение учитывает только латинские буквы:
- Заглавные: `A-Z`
- Строчные: `a-z`

Русские буквы, цифры, пробелы и специальные символы не учитываются.

## Возможности

- Подсчёт латинских букв в выделенном тексте.
- Поддержка заглавных и строчных латинских букв.
- Вывод результата в информационном сообщении VS Code.
- Проверка наличия открытого файла и выделенного текста.

## Как использовать

1. Открой файл в Visual Studio Code.
2. Выдели фрагмент текста.
3. Запусти команду `Count Characters`.
4. В правом нижнем углу появится сообщение с количеством латинских букв.

## Пример

Выделенный текст:

```text
Hello Привет 123! ABC
```

Результат:

```text
Количество латинских букв: 8
```

## Обработка ошибок

Если файл не открыт, расширение выведет сообщение:

```text
Сначала открой файл!
```

Если текст не выделен, появится сообщение:

```text
Сначала выдели текст!
```

## Используемые технологии

- TypeScript
- Visual Studio Code Extension API
- Node.js

## Установка и запуск

1. Открой проект расширения в Visual Studio Code.
2. Установи необходимые зависимости:

```bash
npm install
```

3. Выполни компиляцию:

```bash
npm run compile
```

4. Нажми `F5`, чтобы запустить Extension Development Host.
5. Открой файл, выдели текст и вызови команду расширения.
